# F10 - Health news and Selar links
Size: S · Depends on: F07 (links)

**Story:** As a visitor, I want to read health news and see books for sale so that the site is useful beyond booking.

**Acceptance criteria**
1. Given the news section, Then it shows recent health news that updates automatically with no admin action.
2. Given the news source fails, Then the site still loads and shows the last available news.
3. Given the Selar section, Then it shows the fixed links the admin maintains (F07), each opening the external link.
4. Given no links exist, Then the section is hidden.
