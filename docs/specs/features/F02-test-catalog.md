# F02 - Test catalog and public site
Size: M · Depends on: none (edited later by F07)

**Story:** As a visitor, I want to browse tests with fixed prices so that I know what I can book and what it costs.

**Acceptance criteria**
1. Given the public site, When a visitor opens the catalog, Then they see each test with its name and fixed price.
2. Given a general sample-collection option exists, When the visitor views the catalog, Then it appears as a bookable item with its own price.
3. Given a price is changed (via F07), When the catalog is next loaded, Then the new price shows.
4. Given a mobile screen, When the site is opened, Then the catalog is readable without sideways scrolling.
5. Given the home page, Then it shows the lab name, address and phone numbers as on the result form.
